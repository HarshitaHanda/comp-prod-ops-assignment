02 - The agent

One pipeline. Three deliberately different passes.

The first pass is fast. The second pass is skeptical. The final pass is human.

01

Source-first research

Starts from the official URL supplied in the brief, crawls likely API/auth/docs links on the same official domain, and extracts a structured finding.

  • Auth method(s)
  • Self-serve vs gated
  • REST / GraphQL / MCP
  • Buildability + blocker
  • Evidence URLs + confidence
->
02

Composio enrichment

The official Composio Python SDK loads the live toolkit catalog and records whether the app already has a matching Composio integration.

composio.toolkits.list()
->
03

Independent verification

A separate Chromium/Playwright pass re-renders sampled evidence pages and checks the first-pass claims field by field.

  • Different retrieval path
  • Corrections logged
  • Human sample supported
!
Where a human is still needed

Pricing gates, partner-only access, ambiguous product naming and docs that require an authenticated account can defeat automated retrieval. Those rows are flagged instead of guessed.
